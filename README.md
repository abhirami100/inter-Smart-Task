# Inter Smart Solution

This project is a marketing website created for the Inter Smart task using Next.js, React, TypeScript, and Tailwind CSS.

**Live Website:** https://inter-smart-task.vercel.app/

## Getting Started

Make sure you have **Node.js 20+** and npm installed.

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.

## Available Scripts

- `npm run dev` – Start the development server
- `npm run build` – Build the project for production
- `npm run start` – Run the production build
- `npm run lint` – Check the code with ESLint

## Project Structure

```text
src/
  app/              # Main application files
  components/
    layout/         # Header, footer and navigation
    sections/       # Website sections
    ui/             # Reusable UI components
  lib/              # Static content and data

public/
  assets/           # Images and other assets
```

## Tech Stack

- Next.js (App Router)
