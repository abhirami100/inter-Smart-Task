Tech Stack
Framework: Next.js (App Router) + React

Language: TypeScript

Styling: Tailwind CSS

UI & Animation (Optional): Shadcn UI, Framer Motion

Key Requirements & Code Standards
Component Architecture: Build small, modular, and reusable components. Keep your code DRY (Don't Repeat Yourself) with clear, descriptive naming conventions.

Styling & Layout: Use Tailwind CSS exclusively (no inline styles). Design with a mobile-first responsive approach and maintain consistent spacing throughout the application.

React Best Practices: Use functional components and modern React hooks. Optimize performance to prevent unnecessary re-renders, provide stable key props for lists, and handle asynchronous actions with clear loading states (e.g., skeletons or spinners).
